# CS467 Capstone Project
## Escape Room Challenege
Immersive 3D escape room puzzle game that will put players' problem-solving skills to the ultimate test.

## Features (in progress)
- 3-5 **different** escape rooms
- Each room contains 3 or more **unique** puzzles
- Some puzzles **build on one another**!
- Functional **HUD UI** system

## Technologies 
- Unity Game Engine
- C# (Programming Language)
- Unity Scripting API
- Github
- IDEs (Visual Studio)
