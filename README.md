# CS467 Capstone Project
## Escape Room Challenge

Immersive 3D escape room puzzle game where players solve logic-based puzzles across multiple rooms in order to progress and complete the game.

## Game Overview
Escaptory challenges players to think critically by solving interconnected puzzles across multiple rooms. Players must explore environments, interact with objects, and use logic-based reasoning to progress through each escape room experience.

## Rooms
- **Main Menu** – Allows players to start the game, view credits, or quit the game.
- **Lobby** – The central hub of the game where players choose to begin the Tutorial Room, Room 1, or Room 2.
- **Tutorial Room** – Introduces core gameplay mechanics, controls, and objectives through guided dialogue and interactive puzzles.
- **Room 1** – Room 1 contains three puzzle types: collecting a specific number of balls, cubes, and triangles, guessing a number-based solution, and interacting with ATM machines using the E key to activate the correct pattern sequence.

- **Room 2** – Room 2 contains three puzzle types: finding and collecting all fuses to power the fuse box, rotating switches to match the correct pattern, and unlocking a locker to obtain a hidden fuse needed for progression.

- **Room 3** – Room 3 contains three puzzle types: activating switches in the correct order to open a door, solving a binary number puzzle to unlock another door, and navigating a maze to collect letters and determine the correct word that leads to the final complete scene.

## Features (in progress)
- 3–5 **different** escape rooms
- Each room contains 3 **unique** puzzles
- Some puzzles **build on one another**
- Functional **HUD UI** system (hints, prompts, and countdown system)
- Interactive dialogue and puzzle systems

## Controls
- WASD – Move player
- Mouse – Look around
- E key – Interact with objects and puzzles

## Requirements Summary
- Main Menu system with navigation
- Lobby/Tutorial hub for player onboarding
- Multiple puzzle rooms with progression-based design
- HUD system displaying prompts, hints, and timer
- Interactive puzzle mechanics using Unity physics and triggers
